# SCA CSS Learning Archive

A collection of small HTML and CSS examples used to demonstrate foundational styling concepts. The repository is organized by topic so learners can open individual files and compare CSS techniques.

## Topics Included

- CSS selectors, including element, class, ID, universal, group, and attribute selectors
- CSS units such as pixels, percentages, `em`, `rem`, `vw`, and `vh`
- Colors and backgrounds
- Gradients
- Basic HTML pages with inline, internal, and external CSS
- Small demonstrations for comparing CSS behavior

## Run the Examples

No build tools are required.

```bash
git clone https://github.com/Coderudit05/sca-css-backup.git
cd sca-css-backup
```

Open `index.html` or any topic-specific HTML file in your browser. VS Code Live Server can make editing and previewing easier.

## How to Learn from This Repository

1. Choose one topic folder.
2. Open an HTML example and inspect its CSS.
3. Change one declaration at a time.
4. Refresh the page and observe the result.
5. Compare related examples, especially units and selectors.

## Note

This is a learning archive rather than a polished production application. Some files are intentionally minimal demonstrations and may use generic document titles.
